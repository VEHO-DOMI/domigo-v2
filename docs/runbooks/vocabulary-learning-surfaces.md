## Shared recording paths

**Ordinary completion.** [The attempts route](../../apps/web/app/api/attempts/route.ts) checks the authenticated owner, class scope, mode, grade and reserved items, then regrades the submitted value against current effective content. [recordAttempt](../../packages/db/src/persist.ts) stores item/unit/year, mode, tier, points, optional duration/hint, context, unique event ID and database time. It does not store the raw answer. It also drives review scheduling and reward/streak changes. These side effects are unsuitable for a lookup, a saved-word choice or a non-answer exposure.

**Completed-card metadata.** [Supported history modes](../../apps/web/lib/vocabulary-history.ts) are practice/daily/review and study/journey. They preserve direction, displayed/current content fingerprints, reported check sequence and shown help. Earlier tiers in that completion record are browser claims; only the final submitted answer is regraded there. The server strips client-supplied `context.vocabularyHistory`, so unsupported callers cannot safely add their own authoritative history object.

**Independent checks.** [The check adapter](../../apps/web/lib/vocabulary-history-client.ts), [server boundary](../../apps/web/lib/vocabulary-check-server.ts) and [database writer](../../packages/db/src/vocabulary-checks.ts) separately record each actual Check action, including a wrong check followed by leaving. Each gets a visit ID, event ID, ordinal, direction, displayed/current identity, browser-reported and server-graded tiers, shown help and separate browser/arrival/insertion times. Earlier checks may arrive later. No raw answer or task text is retained in these server history rows. A provisional visit header without a check is not a learning event. This branch must not enter the completion/reward writer.

**Transport and preview.** The [outbox](../../apps/web/lib/attempt-outbox.ts) is browser storage for answers awaiting delivery. Its pending payload includes the raw answer until acknowledgement. Ordinary completions use its owned asynchronous path; independent checks additionally stage synchronously. The remaining two-store replay defect is cgo-145, not declared fixed here. [Preview senders](../../apps/web/lib/preview-attempt.ts) do no network/storage preparation, and hosts disable flushing. A local verdict, a queued request and a confirmed server record are three different states.

## Paint machine semantics

All ten kinds use [the local machines](../../packages/game-paint/src/cards/machines.ts) and CardHost, but only linked choice reaches the shared writer. Local correctness therefore cannot be counted as stored vocabulary history.

| Kind | Actual local grading boundary |
|---|---|
| choice | Selecting an option immediately grades it. Only the first graded linked choice may persist. |
| typed | Editing is pending; explicit submit grades normalized text and accepted forms. |
| spell | Adding/removing letters remains pending until the answer-length tray can be graded. |
| order | Building the full chip arrangement triggers grading. |
| oddone | Single odd-item selection, or multi-selection followed by submit, checks the selected set. |
| wheel | Rotation remains pending; locking chooses the value to grade. |
| mistake | Find the incorrect token; remove-mode completes there, while replace/add proceed to repair. A wrong first-stage selection already fails the try. |
| memory | Mismatched concealed pairs remain pending; all pairs must match to complete. |
| restore | Name and then colour; either stage can be wrong, and saved progress may resume at colour. |
| match | A wrong open-column association fails the try; a complete correct mapping finishes. |

Wrong attempts reset local machine state and can show progressively stronger hints. The bridge's reference-visit boolean does not capture every automatic hint. Timeout and explicit dismissal do not emit an answer. Mapping these cards to vocabulary needs a reviewed task/meaning link, not a guessed join on an English string.

## Interpretation rules for later word help and collection

1. Keep educational meaning, textbook occurrence, task instance, card visit and event identity separate. None of the above inventories resolves the 7,373 unreviewed source cases or certifies first teaching. Do not backfill a meaning link from spelling alone.
2. Preserve interaction type: entered answer, selected option, selected letters, self-rating, pair match, chapter-membership choice, reveal, lookup, skip, timeout and formal submit are not interchangeable. Existing rows often cannot distinguish them retrospectively; label unknown instead of inventing evidence.
3. Keep action time, server arrival and storage time separate. A Paint browser duration and a Live server duration have different authority. Null duration is unknown, not zero.
4. Missing history is not evidence of failure or non-exposure. A pending or lost request is not a deliberate skip. A checkup blank scored zero is not a submitted wrong answer. A local correct verdict is not a storage acknowledgement.
5. Do not turn help or personal saves into answers. A saved word means “I chose to keep this”; it is distinct from both mastery and the automatic spaced-review queue. Images and German help may reveal an answer, so assistance context must follow the exercise mode.
6. Keep chapter-safe vocabulary and grammar, rich contexts, source-bound meanings, Year 1 scaffolding, image dispositions and Activity suitability on the word record. This inventory verifies none of their pedagogical quality; R1–R9 still need their own evidence.
