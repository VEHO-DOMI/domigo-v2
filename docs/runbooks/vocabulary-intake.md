# Vocabulary appendix intake and source resolution

**CODEX DRAFT — NOT CANON.** This tool produces review evidence before the July vocabulary-index contract is frozen. It neither publishes words nor changes grading, learner records, task content or the runtime.

Provide a local JSON manifest with exactly four `{ "grade": 1, "path": "/local/book-1.docx" }` entries, one for each year. Paths may be relative to the manifest. Keep that manifest out of Git: personal source directories are not report metadata. Use only the four textbook appendix word lists, never learner documents.

```
pnpm content vocabulary-intake --manifest /local/appendices.json --out /tmp/vocabulary-intake.json
pnpm content vocabulary-intake --manifest /local/appendices.json --out /tmp/vocabulary-intake.json --verify
```

The initial command refuses an existing output and any output within this repository. Verification recomputes the complete report from the explicit sources and current committed-file inputs, then requires byte equality. It does not rewrite a changed report. Source fingerprints, block/row locators, raw logical cells, corpus file fingerprints, reconciliation decisions and unresolved cases are retained. The existing DOCX reader trims text and omits empty paragraphs; “accounted for” refers to its logical blocks, not byte-for-byte XML round-tripping. Original-file SHA-256 fingerprints retain that distinction.

Report schema `vocabulary-intake-review@2` keeps every original logical row in `rows`. Paragraphs with explicit direct-bold headwords and complete reference/pronunciation/German details become `segmented` parents containing `segments`; the parent text is retained. Consecutive same-format runs are coalesced, including headwords split by Word into several runs. Reference-first and pronunciation-first details are supported. The concatenated child text must equal the entire paragraph. Each child records its parent ID, raw segment, zero-based/end-exclusive text offsets (UTF-16, against concatenated NFC runs before trimming), and original run interval. Unknown formatting, unmatched text or malformed details quarantine the whole paragraph. No boundary is inferred from a dictionary or an English/German-language guess. The optional run preservation does not change other callers of the existing DOCX reader. Years 2–4 have explicit Headword/Reference/German columns, with an optional Phonetics column. Known headings/notes/page markers are labelled metadata; unrecognised shapes, references and empty fields remain quarantined. Every input block/table row has exactly one disposition. A complete accounting is **not** a verified meaning index. `accountedRows` counts original logical rows; `parsedRows` counts directly parsed rows; `parsedEntries` counts in-course table entries plus paragraph children; `excludedEntries` counts preserved out-of-course entries. A segmented parent is not counted again as a word.

Matching only normalises case, Unicode and whitespace. It never strips `to`, optional words or inflections, merges senses, or treats two same-spelling entries as one word. Reference scope and an exact German-text match can establish an exact **textual join**; meaning remains unverified. Multiple same-scope candidates and duplicate source rows remain ambiguous. A prior-book code such as `MORE 1` retains an unknown unit. Standalone episode/section codes such as `OYW3` retain the exact code but require reference review; no unit is guessed. Syntactically valid unit codes outside the current course remain explicit `out-of-course-unit` references, with state `excluded` and reconciliation `outside-current-course`. Their fields survive; they are never renumbered into an existing chapter. Malformed references remain quarantined. An observed appendix code is not proof of first instruction or learner knowledge.

Bank/task coverage uses all 57 unit banks and the existing content pipeline's Git-overlay application. Missing/dropped, renamed and orphaned task IDs are visible. It does not inspect published Studio/database layers; live coverage is explicitly unverified. The existing temporary cross-unit lookup remains unchanged. No production `vocabulary-index@1` is introduced.

Review the quarantine and unmatched/reference-conflict/meaning-review/ambiguous groups before proposing a stable word record. Source reference corrections, curriculum introduction, semantic identities and sentence quality require their own evidence. A word occurring incidentally in a sentence must not automatically become taught vocabulary. The next slice resolves remaining semantic/reference cases and prepares the representative calibration contract; personal saved words and adaptive mastery follow later.

Verification is included in the content-pipeline test suite. Tests cover prior-grade references, flattened paragraphs, duplicates/senses, source-row loss/alteration, unit linkage, deterministic regeneration, and an actual DOCX→CLI→artifact round trip with deliberate row removal. No database or network is needed.

## Source fidelity is separate from curricular and semantic decisions

The October source-resolution run accounts for 6,080 logical rows: 199 metadata rows, 5,803 in-course table entries, 60 Year 1 paragraphs containing 1,577 entries, and 18 excluded Year 4 Unit 14 entries. Thus there are 7,380 in-course source occurrences and 18 excluded occurrences, not 7,398 unique meanings. An independent extraction from the original XML agrees on all 1,577 Year 1 fields and spans. Three Year 1 entries use standalone episode codes and still have no mapped unit. The excluded Year 4 rows genuinely say Unit 14; no inspected evidence supports renumbering them into thirteen units.

A source occurrence, a textual join, a verified meaning, and first teaching are different facts. Zero malformed/unsplit source rows does not resolve semantic disagreements, episode mappings or source-edition identity. None of these reports is a frozen runtime word index. Current book-edition binding and published Studio changes still need independent evidence. See [the vocabulary programme](vocabulary-program.md) for the ordered continuation and the user's expanded teaching, illustration and Activity requirements.
